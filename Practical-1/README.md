# 🎓 StudentHub – Smart Campus Management Portal

# Github - link :- https://github.com/d26cs127-dot/studentHub
## 📖 Overview

StudentHub is a semester-long web application developed as part of the **Web Development Frameworks (ITUE203)** course. The portal provides a centralized platform where students can access academic resources, manage assignments, view attendance, check timetables, receive notices, and manage their profiles.

The project follows a modular development approach, where each laboratory practical adds new features and functionality throughout the semester.

---

## 🎯 Project Objectives

- Develop a centralized student management portal.
- Simplify academic communication between students and faculty.
- Provide easy access to attendance, assignments, notices, and study materials.
- Build a responsive and user-friendly web application.
- Apply modern web development concepts through practical implementation.

---

# 👥 User Role

### Student

The current version of StudentHub is designed primarily for students. Users can:

- Register for an account
- Login securely
- View dashboard
- Check attendance
- View assignments
- Access study materials
- View timetable
- Read notices
- Manage profile
