PRACTICAL 8 - SIMPLE PHP AND MYSQL FILES

1. Start Apache and MySQL in XAMPP.
2. Open http://localhost/phpmyadmin
3. Select Import and import schema.sql.
4. Copy this folder to C:\xampp\htdocs\Practical_8_Simple_Files
5. Open this URL:
   http://localhost/Practical_8_Simple_Files/test_connection.php
6. Take a screenshot of the success message and table.

This version uses mysqli, not PDO, and contains no CSS.
If you import schema.sql more than once, duplicate sample rows may be added.
